공유마당의 각 제공 작품은 ‘만료저작물 / 자유이용’으로 안내된다. [공식 만료저작물 안내](https://gongu.copyright.or.kr/gongu/main/contents.do?menuNo=200091)는 만료된 저작재산권의 자유이용을 설명한다. 코드 MIT를 작품에 덧씌우지 않고 저작자·출처·판본과 처리 범위를 표시한다. 새 CC 라이선스를 부여하지 않는다.

동봉 제공본은 전사 파일이며 원본 지면 사진과 같다는 주장이 아니다. 문학사적 창작/공표 연도는 상세 메타데이터와 제공 파일이 일관되지 않아 기록하지 않는다. 제목만인 `진달래꽃.txt`, `서시(序詩).txt`, `산유화(山有花).txt`는 출처 HTML 고지이며 작품 본문으로 사용하지 않았다. 원본 TXT·PDF 바이트는 변경하지 않았고 PNG는 취득 PDF를 로컬 렌더한 대조 증거다. 원본 해시는 `source-sha256.json`에 기록했다. unit 테스트는 수록 21행과 원본 TXT의 명시한 변환 결과 및 원본 파일 해시를 대조한다. PDF 대조는 렌더를 직접 열어 확인했다.

자료는 런타임 API로 가져오지 않는다. 서버에 원본 PDF를 노출하는 대신 수록 JSON과 출처 고지만 기존 PWA precache에 포함한다.
