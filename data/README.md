# 데이터 출처

`public/data/words.json`의 51개 뜻풀이와 `samples/words.sample.json`은
국립국어원 **한국어기초사전** 공개 원문을 2026-10-09에 확인해 선별한 데이터입니다.
각 항목의 `source`, `provenance`에 원문 URL, 표제어 ID, 의미 번호, 확인일과 가공 내용을 보존합니다.
사전 뜻풀이와 그 가공 데이터는 **CC BY-SA 2.0 KR**로 이용됩니다.
자세한 조건과 가공 내역은 [배포 데이터 이용 안내](../public/data/DATA_LICENSE.txt)를 확인하세요.

기준 커밋 `e4610c1b14fd0ce25203d6cdb81150085ecd733c`의 뜻풀이·예문 출처는
확인되지 않았습니다. ‘직접 작성한 예시’였다는 표시는 근거가 없어 제거했고,
뜻풀이를 공식 원문으로 교체하면서 기존 예문도 삭제했습니다.

낱말 ID, 순서, 표제어, 게임용 난도·대상·태그·이모지는 유지합니다.
그 분류는 사전에서 제공한 교육 등급이 아닙니다. 사전 예문·이미지·발음 음원은 넣지 않습니다.
뜻풀이 문장은 수정하지 않았으며 웹 표시의 공백만 정리했습니다.
‘필통’과 ‘낙엽’은 2번 의미, 다른 낱말은 1번 의미를 선택했습니다.
동음이의어는 과일 ‘사과’, 머리에 쓰는 ‘모자’, 산책 장소 ‘공원’, 명사 ‘내일’,
기록하는 글 ‘일기’, 식물 ‘감자’, 인간 사회의 과정 ‘역사’를 골랐습니다.

## 게임이 읽는 자료

| 자료 | 사용처 | 이번 검증 범위 |
| --- | --- | --- |
| `public/data/words.json` 51개 | 낱말 단계·복습·오늘의 낱말·그림 카드·표준어 낱말 비·낱말 탑·끝말잇기 | 공식 뜻풀이 전체 확인 |
| `public/data/slang.json` | 유행어 카드·스피드 퀴즈·요즘 말/혼합 낱말 비·낱말 탑 | 기존 프로젝트 자료, 공식 사전 검증 아님 |
| 브라우저에 직접 추가한 유행어 | 같은 유행어 게임, 필터·상태·연령 조건 적용 | 사용자 입력, 사전 자료 아님 |
| `public/data/sentences.json` | 짧은/긴 문장, 맞춤법, 속담·사자성어 뜻 퀴즈 | 기존 프로젝트 자료, 작성 경위 별도 확인 필요 |
| `src/spelling/questions.ts` | 헷갈리는 맞춤법 선택 문제 | 기존 프로젝트 자료 |
| `public/data/blocklist.json` | 유행어 필터 | 사전 자료 아님 |

사전 전체를 판정에 사용하는 구조가 아닙니다. 끝말잇기는 앱에 포함된 목록과 연령 필터 안에서만
인정하므로 실제 사전에 있는 말도 거절될 수 있습니다. 자리 연습의 자모와 화면의 예시 단어는
입력 안내이며 별도의 사전 뜻풀이 목록이 아닙니다. 테스트용 가짜 뜻은 게임 배포 데이터가 아닙니다.

API 키나 사전 API 연결 없이 정적 JSON을 동봉하며 PWA에서 캐시합니다.
배포 출처 화면은 `public/licenses.html`, 데이터 고지는 `public/data/DATA_LICENSE.txt`입니다.
`npm run licenses:generate`로 실제 설치된 의존성 고지와 출처 화면을 갱신합니다.
`npm run build`도 이 생성을 먼저 실행합니다.
