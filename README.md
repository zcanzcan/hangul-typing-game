# 한글 타자 게임 (가칭)

학생들이 **한글과 표준어를 타자로 치면서 뜻까지 익히는 웹앱**의 기획 문서 저장소입니다.
한컴타자연습처럼 단계별로 연습하고, 설정에서 **유행어 모드**를 켜면 최신 유행어를 카드게임으로 배울 수 있어요.
초등학생을 기본으로 쉽게 만들고, 성인과 80세 어르신까지 쓸 수 있게 넓힙니다.

> 이 저장소는 아직 코드가 없는 **기획 단계**입니다. 문서를 그대로 바이브코딩(AI 코딩 도구)에 넣어 개발을 시작할 수 있도록 정리했어요.

## 핵심 5가지

| | 내용 |
|---|---|
| 💻 PC와 태블릿 | 설치 없는 웹앱(PWA). 실제 키보드와 화면 키보드 모두 지원 |
| ⌨️ 타자와 뜻 함께 | 치고 나면 뜻 카드가 뒤집히며 표준어 뜻을 함께 익힘 |
| 🔥 유행어 모드 | 설정에서 켜면 최신 유행어 카드게임과 스피드 퀴즈, 미니게임에도 요즘 말이 나옴. 유행어는 주기적으로 업데이트 |
| 🎮 미니게임 | 낱말 비, 끝말잇기, 낱말 탑 쌓기, 요즘 말 스피드 퀴즈 |
| 🏆 점수판 | 내 기록, 가족, 반 점수 비교와 최고 기록 갱신 |
