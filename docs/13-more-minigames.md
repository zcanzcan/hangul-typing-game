# 13. 미니게임 더하기 (끝말잇기, 낱말 탑, 요즘 말 퀴즈)

[12. 낱말 비](12-word-rain.md)에 더해 사람들이 좋아할 만한 미니게임 세 개를 넣는다. 셋 다 **서버 없이 한 기기에서** 돌아간다.

| ID | 게임 | 우선순위 | 누구에게 | 한 줄 설명 |
|---|---|---|---|---|
| T-9 | 끝말잇기 타자 | P1 | 가족, 어르신, 초등학생 | 앞 낱말의 끝 글자로 시작하는 낱말을 번갈아 친다 |
| T-10 | 낱말 탑 쌓기 | P1 | 어르신, 저학년 (모두) | 맞게 치면 블록이 한 층씩 올라간다. 시간 제한 없음 |
| S-8 | 요즘 말 스피드 퀴즈 | P1 | 유행어 모드 사용자 | 뜻을 보고 그 유행어를 빨리 친다 |

공통 규칙

- 한글 입력 판정은 [04](04-typing-and-scoring.md), 제출(Enter) 처리는 [12](12-word-rain.md) 5절을 그대로 쓴다. 조합 중 Enter는 조합이 끝난 값으로 한 번만 제출하고, 빈 입력칸의 Enter는 무시한다.
- 낱말은 앱 안의 목록만 쓴다: `words.json`(연령대 `audience`, `level`에 맞는 것), 유행어 모드가 켜져 있으면 `slang.json`의 `status: "active"`와 사용자가 추가한 유행어. 초등학생 프로필은 `kidSafe: true` 유행어만 쓴다.
- 모든 게임은 공통 결과 화면으로 끝나고([03](03-screens-and-flow.md)), 기록은 `Record.mode: "minigame"`에 `Record.game`으로 게임을 구분한다([05](05-data-model.md)). 최고 기록 갱신 축하와 "+12점" 차이 표시는 04 공통 규칙을 따른다.
- 기록 값: `cpm`은 맞게 낸 낱말의 자모 수 ÷ 게임 시간(분), `accuracy`는 맞은 제출 ÷ 전체 제출 × 100, `durationSec`는 게임 시간, `score`는 게임별 점수. 틀린 낱말은 `Mistake`로 저장한다.
- 시간 제한 없이 한 판(어르신 기본, 낱말 탑 기본)은 04의 "시간 제한 없음" 규칙처럼 **정확도와 완료 개수**를 앞에 보여주고, 점수판에서 시간 제한 있는 판과 따로 비교한다.
- 이름과 화면은 새로 만든다. 한컴타자의 게임 이름("동전쌓기", "판뒤집기" 등)과 화면 디자인을 쓰지 않는다 ([CLAUDE.md](../CLAUDE.md), [09](09-open-questions.md)).
- 수치(시간, 점수)는 첫 버전의 출발값이며 사용자 테스트 후 조정한다.

## T-9. 끝말잇기 타자

### 규칙

| 항목 | 내용 |
|---|---|
| 인원 | **컴퓨터와 1:1** 또는 **한 기기에서 2~4명이 번갈아** (가족 점수판 R-4의 닉네임을 고른다) |
| 차례 | 앞 낱말의 **끝 글자로 시작하는** 낱말을 입력칸에 치고 Enter |
| 인정 조건 | 두 글자 이상 / 앱 낱말 목록에 있는 말 / 이번 판에 아직 안 나온 말 |
| 두음 법칙 | 켜기가 기본. 끝 글자가 `력`이면 `역`으로도 시작할 수 있다 (아래 표) |
| 차례 시간 | 초등학생 20초, 성인 10초, 어르신 **제한 없음** |
| 탈락 | 시간 안에 못 치거나, 인정 조건에 맞지 않는 말을 **3번** 내면 그 사람은 이번 판에서 빠진다 |
| 끝 | 한 사람만 남으면 끝. 컴퓨터와 할 때는 내가 빠지거나 컴퓨터가 이을 낱말이 없으면 끝 |
| 힌트 | 초등학생·어르신은 "힌트" 버튼으로 이을 수 있는 낱말의 첫 두 글자 초성을 본다 (한 판에 3번) |

- 틀린 말을 내면 이유를 알려준다: "끝 글자 '과'로 시작해야 해요", "이미 나온 말이에요", "낱말 목록에 없는 말이에요".
- 목록에 없는 말은 인정하지 않는다. 사전을 인터넷으로 찾지 않는 대신, 틀린 이유를 "목록에 없는 말"로 부드럽게 알린다.
- **이을 낱말이 목록에 하나도 없는 끝 글자**(예: `…늄`)로 끝나는 말은 초등학생·어르신 판에서는 내지 못하게 막고 "다른 낱말을 골라 보세요"라고 안내한다. 성인 판에서는 허용하고, 다음 사람이 못 이으면 낸 사람이 이긴다.
- 컴퓨터는 목록에서 무작위로 고르되, 연령대에 맞는 쉬운 낱말(`level` 낮은 것)을 먼저 고른다. 컴퓨터도 같은 차례 시간을 쓰고, 1~2초 뒤에 한 글자씩 쳐서 보여준다.

### 두음 법칙 표

[한글 맞춤법 제10~12항](10-verification.md#13번-문서미니게임-3개-검증-jev)을 끝말잇기용으로 줄인 것이다. 끝 글자의 첫소리와 가운뎃소리만 보고, 받침은 그대로 둔다 (`력` → `역`, `림` → `임`).

| 끝 글자 | 이렇게도 시작할 수 있음 | 예 |
|---|---|---|
| ㄴ + ㅕ ㅛ ㅠ ㅣ (`녀 뇨 뉴 니`) | ㅇ | 여자 → 자녀 → **여**행 |
| ㄹ + ㅑ ㅕ ㅖ ㅛ ㅠ ㅣ (`랴 려 례 료 류 리`) | ㅇ | 경력 → **역**사 |
| ㄹ + ㅏ ㅐ ㅗ ㅚ ㅜ ㅡ (`라 래 로 뢰 루 르`) | ㄴ | 쾌락 → **낙**엽 |

- 구현: `es-hangul`의 `disassemble`/`assemble`로 첫소리를 바꾼 글자를 만든다 (라이브러리에 두음 법칙 함수는 없어 직접 짠다).
- 두음 법칙은 한자어 규칙이지만 게임에서는 모든 낱말에 똑같이 적용한다 (끝말잇기에서 흔히 쓰는 방식).

### 점수

- 인정된 낱말마다 **글자 수 × 10점**
- 차례 시간이 있을 때, 남은 시간 절반 이상에서 치면 +10점
- 마지막까지 남은 사람 +50점
- 결과 화면: 사람별 점수, 이은 낱말 수, 이번 판 낱말 사슬 전체 (낱말을 누르면 뜻 카드)

## T-10. 낱말 탑 쌓기

### 규칙

| 항목 | 내용 |
|---|---|
| 진행 | 화면에 낱말이 하나씩 나온다. 맞게 치고 Enter를 누르면 그 낱말이 적힌 블록이 탑 위에 한 층 쌓인다 |
| 틀림 | 한 글자라도 틀리면 탑이 **한 번 흔들린다**. 같은 낱말이 다시 나온다 |
| 무너짐 | 흔들림이 **3번** 쌓이면 탑이 무너지고 게임 끝 |
| 회복 | 5개 연속으로 맞히면 흔들림 1번이 사라진다 |
| 시간 | **제한 없음** (기본). 성인은 "60초 도전"을 고를 수 있다 |
| 꾸러미 | 표준어 / 요즘 말 / 섞어서 ([12](12-word-rain.md) 2절과 같은 규칙) |
| 층 표시 | 10층마다 배경이 바뀐다 (땅 → 구름 → 우주) |

- 어르신과 저학년이 서두르지 않고 정확하게 치는 연습이 목적이다. 그래서 속도보다 **정확도**에 점수를 준다.
- 블록을 누르면 그 낱말의 뜻 카드가 나온다. 끝난 뒤 "내 탑 둘러보기"로 쌓은 낱말을 다시 볼 수 있다.

### 점수

- 블록마다 **글자 수 × 10점**
- 10층마다 +50점
- 60초 도전은 04의 점수 공식(`타수 × (정확도/100)² × 단계 보너스`, 단계 보너스 1.2)을 쓴다
- 틀린 낱말은 틀린 낱말(`Mistake`)로 저장한다

## S-8. 요즘 말 스피드 퀴즈

유행어 카드게임(S-2)은 **유행어를 보고 뜻을 고르는** 게임이고, 이 게임은 거꾸로 **뜻을 보고 유행어를 쳐서 맞히는** 게임이다. **유행어 모드(S-1)가 켜져 있을 때만** 메뉴에 보인다. 화면은 07의 픽셀 테마.

### 규칙

| 항목 | 내용 |
|---|---|
| 문제 | 뜻(`meaning`)과 비슷한 표준어(`standardForm`)를 보여준다. 예문(`example`)이 있으면 유행어 자리를 `○○`로 가린 채 함께 보여준다 |
| 답 | 그 유행어를 치고 Enter. 띄어쓰기는 무시하고 비교한다 |
| 한 판 | 10문제. 유행어가 10개보다 적으면 있는 만큼, **4개 미만이면** "요즘 말이 더 필요해요" 안내와 함께 설정의 유행어 추가로 보낸다 |
| 시간 | 문제당 초등학생 20초, 성인 10초, 어르신 제한 없음 |
| 힌트 | 시간의 절반이 지나면 초성이 나온다 (`갓생` → `ㄱㅅ`, `es-hangul`의 `getChoseong`). 어르신은 "힌트" 버튼으로 본다 |
| 틀림 | 한 문제에 두 번까지 다시 칠 수 있다. 그래도 틀리거나 시간이 지나면 정답과 뜻을 보여주고 다음 문제로 간다 |

### 점수

카드게임(04) 점수와 모양을 맞춘다.

- 정답 **+100**
- 빠르기 보너스: 남은 시간(초) × 5 (시간 제한 없음이면 없음)
- 힌트를 보고 맞히면 −30 (최소 +50)
- 3연속 정답부터 문제당 **+20** 콤보
- 틀린 유행어는 틀린 낱말(`Mistake`)로 저장해 카드게임 복습에도 나오게 한다

## 개발 순서

[11](11-dev-steps.md) 5단계 안에서 기능 하나당 PR 하나로 만든다.

1. 낱말 비 (T-8)
2. 요즘 말 스피드 퀴즈 (S-8): 3단계 유행어 모드가 있으면 바로 만들 수 있다
3. 낱말 탑 쌓기 (T-10)
4. 가족 점수판 (R-4)
5. 끝말잇기 타자 (T-9): 여럿이 하려면 R-4의 닉네임 고르기가 필요하므로 R-4 다음

게임 규칙은 화면과 떼어 `src/games/<게임>/`의 순수 함수로 만들고 단위 테스트를 붙인다.

| 게임 | 단위 테스트에 넣을 것 |
|---|---|
| 끝말잇기 | 끝 글자 잇기, 두음 법칙 표의 세 줄(`녀→여`, `력→역`, `락→낙`)과 받침 유지, 이미 나온 말 거절, 목록에 없는 말 거절, 한 글자 낱말 거절, 3번 틀리면 탈락, 초등학생 판에서 이을 수 없는 끝 글자 막기 |
| 낱말 탑 | 블록 점수, 10층 보너스, 흔들림 3번에 끝, 5연속 정답에 흔들림 회복 |
| 요즘 말 퀴즈 | 정답 +100, 빠르기 보너스, 힌트 −30과 최소 +50, 3연속 콤보, 띄어쓰기 무시 비교, 유행어 모드가 꺼져 있으면 게임이 없음, 초등학생은 `kidSafe`만, 4개 미만이면 시작 안 됨 |
