# 14. 고전문학 타자 연습

## 목표와 첫 범위

작품을 읽으며 한 구절씩 따라 치는 싱글플레이 연습이다. 낱말 비·끝말잇기·낱말 탑과 독립된 메뉴로 모든 연령에 열린다. 시간 제한, 목표 속도, 순위, 속도 점수는 없다. 기존 프로필의 글자 크기와 키보드 설정을 따른다. DB·로그인·런타임 AI·파일 업로드·외부 콘텐츠 API를 추가하지 않는다.

**흐름:** 메뉴 → 작품 선택 → 작가·시대 분류·원문 판본·출처·이용조건·가공 내역 확인 → 시작 → 현재 구절 읽고 입력 → 명시적 확인 버튼 → 다음 구절 → 완료 요약 → 같은 작품 다시하기 / 다른 작품 / 메인.

작품은 `고전문학`과 `근대문학`으로 구분한다. 윤동주·김소월 등의 근대 시를 전근대 고전으로 표시하지 않는다. 작품 바꾸기·처음부터 다시·메인으로는 미완료 연습을 버리고 저장하지 않는다. 페이지 새로고침도 미완료 연습을 복원하지 않는다. 완료 기록은 선택 화면의 최근 문학 연습에서 확인한다.

## 입력과 수치 규칙

- 제시문과 입력은 판정 시 NFC로 정규화한다. 입력 DOM은 조합·커서를 유지하기 위해 그대로 둔다.
- 띄어쓰기·문장부호·따옴표·선행/후행 공백은 제시문과 정확히 같아야 한다. trim, 자동 철자 교정, 따옴표 치환을 하지 않는다. CRLF/CR/LF는 각각 공백 한 칸으로 비교한다. 연속 공백/줄바꿈을 하나로 합치지 않는다. 탭·NBSP를 일반 공백으로 치환하지 않는다.
- 작품 데이터의 구절 경계는 `passages[]`다. 원문의 개행을 구절로 나눈 가공 내역을 명시한다. 한 구절에는 개행·탭이 없도록 사전 검증한다. 구절 사이의 개행은 입력하거나 타수에 포함하지 않는다. 긴 구절의 화면 자동 줄바꿈은 입력과 무관하다.
- `<textarea>`의 현재 값을 받아 판정한다. `compositionstart`~`compositionend` 동안 확인 버튼을 비활성화하고 제출을 막는다. 조합 중 불일치는 중간 위치 수정까지 ‘조합 중’으로 보류한다. 조합 종료와 뒤따르는 input이 같은 값을 보내도 자동 제출하지 않는다. 글자 판정에 keydown/keyCode를 쓰지 않는다.
- 틀렸거나 덜 적은 구절은 확인 후 수정할 수 있다. Backspace·Delete·중간 커서 이동·선택 영역 교체를 허용한다. 정확히 같은 구절을 확인해야 다음 구절로 간다. Enter는 제출하지 않고 입력 줄바꿈이다. 마지막 구절도 명시적 완료 확인이 필요하다.
- 붙여넣기와 드롭은 막고 안내한다. paste/drop 이벤트와 `beforeinput`/input의 `insertFromPaste`·`insertFromDrop`을 방어한다. OS가 일반 insertText처럼 보내는 클립보드·음성·보조 입력은 웹에서 완전히 구별할 수 없다. 기록은 인증된 경쟁 성적이 아니다.
- **진행률:** (확인 완료한 구절의 글자 수 + 현재 구절의 위치가 맞는 확정 글자 수) / 전체 구절 글자 수 × 100. 공백·문장부호 포함, NFC 후 유니코드 코드포인트 기준. 조합 중 글자는 아직 확정된 맞음으로 더하지 않는다. 100% 표시 뒤에도 완료 확인을 눌러야 저장된다.
- **확인 정확도:** 확인 버튼을 누른 각 구절에서 위치가 맞는 글자 수의 합 / 각 확인의 `max(제시문 길이, 입력 길이)` 합 × 100. 빠진 글자와 초과 입력도 정확도를 낮춘다. 같은 구절에서 동일한 정규화 입력을 연속 재확인해도 집계는 한 번이다. 수정한 값을 다시 확인하면 새 확인으로 집계한다. 틀린 확인도 누적되며, 확인 전에 고친 오타는 누적하지 않는다. 예: 제시문 `강`에 `감` 확인 후 `강` 수정 확인, 이어서 `사과.`를 확인하면 4/5 = 80%다. 화면 글자별 ✓/✗/…는 실시간 도움이며 확인 정확도와 구분한다.
- **자소·참고 타수:** 기존 `countKeystrokes`/`calculateCpm`을 재사용한다. `사과`=5자소, 쌍자음=1타, 겹모음·겹받침은 분해된 자소 수, 공백·문장부호=각 1타. 완료한 구절의 자소 합 / 걸린 초 × 60. 수정·삭제·오답 재입력 자소는 추가하지 않는다. 진행 중에는 완료한 구절만 분자에 들어가며 첫 구절 확인 전 타수는 0이다.
- **시간:** 시작 버튼이 아니라 첫 비어 있지 않은 입력부터 마지막 확인까지. 읽기·쉬기·다른 탭에 머무는 시간도 포함한다. 재시작은 0으로 초기화한다. 0초에서는 타수 0을 반환하여 NaN/Infinity를 막는다. 표시만 반올림하고 기록에는 원값을 저장한다.
- **점수:** 이 모드는 속도 기반 점수·단계 통과·최고 기록·가족 순위에 참여하지 않는다. 정확도·완료 구절·참고 타수·시간만 기록한다. 기존 문장 연습과 지표가 다른 점은 사용자 안내에 명시한다.

## 작품과 권리

`src/literature/works.json`은 검증된 작품만 담는다. 각 항목에 ID·내용 버전·제목·작가·시대·판본·공식 출처 URL·이용조건 URL·재사용 조건·가공 내역·원문 대조일·`verification: verified`·실제 구절을 넣는다. 목록 등록 전 원문 파일을 취득해 **선택한 판본의 문장·철자·구두점까지 대조**하고 근거를 보존한다. 오래된 작가라는 사실이나 상세 페이지의 자유이용 배지만으로 판본·번역·현대어 가공의 이용조건까지 추정하지 않는다.

첫 목록은 공유마당 제공 「진달래꽃」(9000320, 김소월) 12행과 「서시」(9000779, 윤동주) 9행이다. 모두 **근대문학**으로 표시한다. 사용자가 승인한 이용범위 체크와 다운로드 이용 목적 설문으로 공식 ZIP을 취득했다. 동봉 TXT와 PDF의 본문을 대조했다. 제공 파일의 제목·작가 표제·빈 행을 제외하고 행 끝 공백 정리 및 NFC 정규화만 적용했다. 한자 병기와 제공 판본의 철자·띄어쓰기·구두점은 유지했다. 파일명의 문헌명은 판본 식별용이며, 원본 지면 사진이나 역사적 첫 발표본과 같다고 주장하지 않는다. 상세 페이지의 서로 맞지 않는 창작·공표 연도는 복사하지 않았다.

「산유화」(9029202)는 다운로드한 공식 판본에 옛 표기 및 PUA 문자 ``(U+E9EA)이 있어 보류했다. 현대 철자를 기억이나 AI로 복원하지 않았다. 취득 TXT·PDF·PDF 렌더 PNG와 SHA-256은 `data/literature/`에 보존한다. 제목만 붙은 TXT 파일은 시 본문이 아니라 HTML 출처 고지이므로 원문으로 사용하지 않았다. 자세한 원문 대조는 [출처 검증](../data/literature/README.md)을 참고한다.

`fixtures.ts`의 직접 작성 문장은 unit 테스트에만 명시적으로 사용한다. 작품 목록이 비었을 때만 DEV 동적 import가 fallback을 제공하며, 공개 빌드와 배포 JSON에는 fixture가 없다.

코드 MIT와 작품 데이터 라이선스는 별개다. `scripts/verify-literature.mjs`가 미검증 표시·누락 출처·중복 ID·빈 구절·NFC 오류 등을 빌드 전에 거부한다. 이 구조 검사는 실제 원문 대조를 대신하지 않는다. `scripts/generate-notices.mjs`가 작품별 출처를 `public/licenses.html`, `public/data/literature.json`, `public/data/LITERATURE_LICENSE.txt`에 생성한다. 기존 국립국어원 CC BY-SA 고지를 유지한다. JSON을 수정했다면 `npm run licenses:generate`로 고지를 재생성한다.

## 저장·접근성·PWA

새 localStorage 키 `hangul-typing-game-literature-v1`에 최근 100회(모든 프로필 합)를 저장한다. 기존 프로필 ID와 작품 ID·버전으로 구분한다. 프로필 ID는 기존 앱의 로컬 무작위 ID이며 서버 전송하지 않는다. 선택 화면은 해당 프로필 최근 10회를 보여준다. 완료 ID의 중복 저장을 막는다. 설정의 기존 확인 대화상자 후 기록 초기화는 문학 기록도 지운다. 저장 차단/용량 초과/손상 데이터에서는 완료 요약을 유지하고 실패 안내·다시 저장 버튼을 제공한다. 손상 데이터를 자동 덮어쓰지 않는다.

기존 연령별 글자 크기에 문학 전용 100/125/150/175/200% 확대를 곱한다. 작품 선택·출처·입력·완료 모두에 적용한다. ‘글자 줄이기 / 키우기 / 기본 크기’는 현재 입력과 진행을 유지한다. `hangul-typing-game-literature-font-v1`에 기기 공통 설정을 저장하며 초기화는 키를 삭제한다. 잘못된 값·읽기 차단은 기본값과 안내로 복구하고, 쓰기 실패에도 현재 화면의 확대는 적용한다. 부모 앱의 확대 설정과 브라우저 줌을 막지 않는다. 320px 및 어르신 기본 크기 × 200%에서 단일 열로 재배치한다. CSS 변수·48px 버튼·포커스를 따른다. 색 외에도 ✓/✗/…와 상태 문구를 사용한다. 모바일 헤더를 한 열로 배치한다. 선택한 화면 키보드를 사용하면 기존 자모 조합·삭제와 현재 구절의 문장부호 버튼을 제공한다. 모바일 실제 OS 키보드 높이 변화는 기존 visualViewport 처리를 활용한다.

PWA 설정·등록 방식은 바꾸지 않는다. 새 앱 번들·정적 JSON·고지가 기존 precache glob에 포함되고 `cleanupOutdatedCaches`가 캐시를 정리한다. 기존 저장소 키는 마이그레이션·삭제하지 않는다. 로컬 제작 빌드의 오프라인·캐시 테스트와 이전 설치본에서 새 버전으로의 실제 업데이트 검증은 구분한다. 이전 배포 PWA 설치본 업데이트와 iOS/Android 홈 화면 설치·가상 키보드는 실기기에서 별도 확인해야 한다.

## 검증과 공개 전 확인

unit: NFC·공백/구두점·줄바꿈·조합·중간 수정·자소/0초, 중복 저장·프로필 분리·100회·손상/차단/용량, 화면의 IME 종료/trailing input·오답 수정·붙여넣기·드롭·재시작·작품 교체·완료중복·저장재시도.

e2e: 출처→입력→완료→기록 보존, 작품 교체/뒤로가기/재시작, 세 기존 게임 메뉴 회귀, 저장 오류·설정 초기화, 360/390px Chromium(어르신 글자 크기)의 가로 넘침·완료·출처. 기존 전체 unit/e2e/lint/typecheck/build 및 PWA 검사도 실행한다. 증거와 명령 결과는 `docs/evidence/classic-literature/README.md`를 참고한다.

자동화의 `CompositionEvent`/`InputEvent`는 앱 이벤트 처리만 검증한다. Playwright fill은 실제 한국어 IME가 아니다. PC 한국어 IME, iPad Safari, Android Chrome의 자판·조합 확정·커서 중간 수정·선택 교체·키보드 가림·회전은 **미확인**이다. 실제 기기의 IME·브라우저 줌·기존 설치 PWA 업데이트는 별도 확인 사항이다. 최초 개발은 로컬 전용이었으며 이후 사용자 배포 승인에 따라 PR·CI 검증을 거쳐 기존 GitHub/Vercel 연결로 공개한다.
