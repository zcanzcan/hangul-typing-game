# 09. 확인할 것

개발 전후로 확인해야 할 질문과 현재 판단이다. "확인 필요"는 아직 검증하지 않은 내용이다.

| 질문 | 현재 판단 | 상태 |
|---|---|---|
| 표준어 낱말과 뜻 데이터는 어디서? | **한국어기초사전**(쉬운 뜻풀이, 초등학생에 적합)을 기본으로, 부족하면 표준국어대사전·우리말샘. 세 곳 모두 오픈 API가 있고 CC BY-SA 2.0 KR로 공개(2차 검증). 조건: 출처 표시, 낱말 데이터 파일은 CC BY-SA로 공개, **예문과 그림은 직접 만들기**. 2026-10-09 한국어기초사전 공식 원문과 51개 의미 확인, 예문 미포함. [현재 데이터 범위](../data/README.md) | 정적 데이터 교체 완료 |
| 유행어 출처와 업데이트 주기 | 월 1회, 출처 2개 이상 교차 확인 ([06. 유행어 운영](06-slang-operations.md)) | 초안 |
| 참고할 오픈소스 | 한글 처리는 `es-hangul`(MIT) 사용으로 결정. 타자 게임 오픈소스는 라이선스 확인 후 판정 로직만 참고 | 일부 결정 |
| 점수판 저장: 기기 안 vs 서버 | 내 기록과 가족 점수판은 기기 안에 저장. 반 점수판만 전용 `hangul-typing-game` Supabase 프로젝트에 저장 | 결정·구현 |
| 어린이 개인정보 기준 | 개인정보 보호법 제22조의2(검증 완료)상 만 14세 미만 개인정보 처리에는 법정대리인 동의가 필요. 반 점수판은 개인정보 수집을 피하도록 무작위 반 코드·닉네임·점수·모드·단계·기록 시각만 저장하고, 30일 뒤 앱 접근을 만료하며, 실명·연락처·로그인 계정·기기 식별자를 받지 않음 | 정책 결정·구현 |
| 한컴 이름, 디자인 | "한컴", "한컴타자연습"은 한글과컴퓨터의 제품 이름(상표 등록 여부는 미확인, 보호될 수 있다고 보고 대응). 서비스 이름, 로고, 화면 디자인을 따라 하지 않고 "한컴타자 같은" 표현은 기획 문서 안에서만 씀 | 결정 |
| 서비스 이름 | 미정. 후보 예: "한글 톡톡", "말랑타자", "뜻쏙타자" (기존 서비스 "타닥타닥타자연습"과 겹치지 않게, 정하기 전 이름 검색 필요) | 정해야 함 |
| 글꼴 라이선스 | 배민 주아, Pretendard, 갈무리, Neo둥근모 모두 웹 사용 가능 확인 | 결정 |
| 캐릭터 | 칭찬 캐릭터 직접 그리기 vs 무료 일러스트 | 정해야 함 |

전체 검증 내역은 [10. 사실 검증 결과](10-verification.md)에 있다.
