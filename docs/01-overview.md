# 01. 개요와 대상

## 한 줄 소개

학생들이 한글과 표준어를 **타자로 치면서 뜻까지 익히는 웹앱**. 한컴타자연습처럼 단계별로 연습하고, 유행어 모드로 요즘 말도 배운다.

## 목표

1. 한글 자판(두벌식) 자리를 익히고 타자 속도와 정확도를 올린다.
2. 표준어 낱말과 뜻, 헷갈리는 맞춤법을 자연스럽게 익힌다.
3. 최신 유행어를 카드게임으로 배워 세대 간 언어 차이를 줄인다.
4. 점수판과 최고 기록 갱신으로 꾸준히 연습할 동기를 준다.
5. 키보드가 불편한 학생은 태블릿 화면 키보드로도 똑같이 할 수 있다.

## 대상별 설계

처음 접속할 때 **연령대를 고르면** 글씨 크기, 속도, 난이도가 자동으로 맞춰진다. 설정에서 언제든 바꿀 수 있다.

### 초등학생 (기본 대상)

| 구분 | 내용 |
|---|---|
| 합의된 아이디어 | 자리 익히기 → 낱말 → 짧은 문장 순서로 단계 상승 |
| | 그림 카드로 뜻 보여주기 |
| | 캐릭터와 칭찬 스티커 |
| 추가 제안 | 받침, 쌍자음 단계를 따로 두기 |
| | 다음에 누를 자리를 화면 키보드에서 빛내기 |
| | 하루 10분 목표 도장 |

### 성인

| 구분 | 내용 |
|---|---|
| 합의된 아이디어 | 긴 문장 연습 |
| | 헷갈리는 맞춤법 (예: 되/돼, 안/않) |
| | 속도와 정확도 기록 |
| 추가 제안 | 속담, 사자성어 뜻 퀴즈 |
| | 틀린 맞춤법 고치기 모드 |

### 어르신 (80세까지)

| 구분 | 내용 |
|---|---|
| 합의된 아이디어 | 큰 글씨, 느린 속도 |
| | 시간 제한 없는 연습 |
| | 소리로 읽어주기 |
| | 단순하고 큰 버튼 |
| 추가 제안 | 손주와 같이 하는 가족 대결 |
| | 글자 크기 3단계 조절 |

## 연령대 프리셋 (기본값)

| 항목 | 초등학생 | 성인 | 어르신 |
|---|---|---|---|
| 기본 글자 크기 | 보통(20px) | 보통(18px) | 크게(28px) |
| 시작 단계 | 자리 연습 | 낱말 | 자리 연습 |
| 시간 제한 | 있음(넉넉히) | 있음 | **없음** |
| 미니게임 낙하 속도 | 느림 | 보통 | 매우 느림 |
| 소리 읽어주기 | 켜짐 | 꺼짐 | **켜짐** |
| 유행어 모드 | 꺼짐 | 꺼짐 | 꺼짐 |
