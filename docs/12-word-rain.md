# 12. 낱말 비 (떨어지는 낱말 막기)

> 다른 미니게임(끝말잇기, 낱말 탑 쌓기, 요즘 말 스피드 퀴즈)은 [13. 미니게임 더하기](13-more-minigames.md)에 있다.

위에서 비처럼 떨어지는 낱말을 바닥에 닿기 전에 입력해서 없애는 게임이다. 기능 번호는 [02](02-features.md)의 **T-8**, 우선순위 **P1**, 개발은 [11](11-dev-steps.md)의 **5단계 첫 번째 PR**이다.

한컴타자의 "산성비"처럼 떨어지는 낱말을 치는 방식은 타자 게임에서 흔한 장르다 ([검증](10-verification.md#12번-문서낱말-비-검증-jev)). 다만 이 앱은 **"산성비" 이름, 산성도(pH) 설정, 한컴 화면 디자인을 쓰지 않는다** ([CLAUDE.md](../CLAUDE.md), [09](09-open-questions.md) 상표 항목). 대신 바닥의 **새싹 3개**를 지키는 이야기로 바꾼다.

## 1. 규칙

| 항목 | 내용 |
|---|---|
| 목표 | 낱말 빗방울이 바닥에 닿기 전에 입력해서 없앤다 |
| 입력 | 화면 아래 입력칸 하나. 낱말을 치고 **Enter**(태블릿은 화면 키보드의 확인)로 제출 |
| 맞힘 | 화면에 있는 낱말 중 입력과 똑같은 것이 있으면 없앤다. 같은 낱말이 여러 개면 **가장 아래 것**을 없앤다 |
| 틀림 | 입력칸이 살짝 흔들리고 비워진다. 점수 감점은 없고 연속 기록(콤보)만 끊긴다 |
| 놓침 | 낱말이 바닥에 닿으면 새싹 하나가 시든다. **3개가 모두 시들면 끝** |
| 빨라짐 | 30초마다 낙하 속도 10% 증가. 시작 속도의 2.5배에서 멈춘다 |
| 멈춤 | 일시정지 버튼(48px 이상). 다른 탭으로 가면 자동으로 멈춘다 |

### 연령대 프리셋

[01](01-overview.md)의 "미니게임 낙하 속도"를 구체적인 값으로 정한 것이다. 수치는 출발점이며 사용자 테스트 후 조정한다.

| 항목 | 초등학생 | 성인 | 어르신 |
|---|---|---|---|
| 시작 낙하 시간 (위→바닥) | 12초 | 8초 | 16초 |
| 화면에 동시에 떠 있는 최대 낱말 수 | 4 | 6 | 3 |
| 낱말 길이 | 1~3글자 | 2~5글자 | 1~3글자 |
| 새싹(목숨) | 3 | 3 | 3 |

- 설정의 "속도 조절"(A-4)이 켜져 있으면 시작 속도를 한 단계 더 느리게 할 수 있다.
- 어르신 "시간 제한 없음" 설정이어도 이 게임은 떨어지는 속도가 있으므로, 메뉴에서 "천천히 내리는 비" 안내 문구를 보여준다.

## 2. 낱말 꾸러미 (요즘 말 포함)

시작 화면에서 꾸러미를 고른다.

| 꾸러미 | 낱말 출처 | 조건 |
|---|---|---|
| 표준어 | `words.json` (연령대 `audience`, `level`에 맞는 것) | 항상 선택 가능 |
| 요즘 말 | `slang.json`의 `status: "active"` + 사용자가 추가한 유행어(`customSlang`) | **유행어 모드(S-1)가 켜져 있을 때만** 보인다 |
| 섞어서 | 표준어 70% + 요즘 말 30% | 유행어 모드가 켜져 있을 때만 |

- 초등학생 프로필은 `kidSafe: true`인 유행어만 나온다. 기본 목록은 [06](06-slang-operations.md) 검수를 거친 것만 들어가고, 사용자가 추가한 유행어도 금칙어 필터를 통과한 것만 저장되므로 두 겹으로 거른다.
- `status: "archived"`(옛 유행어)는 기본으로 빠진다.
- 띄어쓰기가 있는 표현과 연령대 글자 수를 넘는 말은 뺀다. 요즘 말이 5개 미만이면 표준어로 채우고 "요즘 말이 부족해서 표준어를 섞었어요"라고 알린다.
- 요즘 말 목록은 [06](06-slang-operations.md)의 월 1회 업데이트를 그대로 따르므로, 목록이 바뀌면 이 게임에도 바로 새 말이 내린다. 게임을 위한 별도 목록은 만들지 않는다.

## 3. 점수

[04](04-typing-and-scoring.md)의 미니게임 점수를 그대로 쓴다.

- 낱말을 없앨 때마다 **글자 수 × 10점** (`갓생` = 20점, `사과` = 20점)
- 표준어와 요즘 말의 점수는 같다
- 결과 화면에 함께 보여주는 값
  - 없앤 낱말 수, 놓친 낱말 수, 최대 콤보, 버틴 시간
  - 타수: 맞게 없앤 낱말의 자모 수 ÷ 게임 시간(분) ([04](04-typing-and-scoring.md) 타수 정의)
  - 정확도: 맞은 제출 ÷ 전체 제출 × 100
- 최고 기록은 **닉네임 × 모드 × 꾸러미**별로 저장한다 (표준어와 요즘 말 기록을 섞지 않는다).
- 최고 기록 갱신 축하(색종이, 캐릭터 칭찬, 스티커)와 "이전 최고 기록 대비 +12점" 차이 표시는 [04](04-typing-and-scoring.md)의 공통 규칙을 그대로 쓴다. 기록은 `Record.mode: "minigame"`, `Record.game: "wordRain"`, `Record.pack`에 꾸러미를 넣는다 ([05](05-data-model.md)).

## 4. 뜻 익히기와 연결

- 결과 화면에 **"오늘 내린 요즘 말"** 카드를 보여준다. 이번 판에 나온 유행어의 뜻, 비슷한 표준어(`standardForm`)를 함께 보여줘서 요즘 말과 표준어를 같이 익힌다.
- 놓친 낱말은 틀린 낱말(`Mistake`)로 저장해 "다시 연습"에 모은다.

## 5. 한글 입력 처리

[04](04-typing-and-scoring.md)의 규칙을 그대로 따르고, 이 게임에서 특히 챙길 점만 적는다.

- 판정은 **제출할 때 한 번**만 한다. 조합 중 글자로 낱말을 없애지 않는다.
- 한글 조합 중에 Enter를 누르면 브라우저마다 이벤트 순서가 다르다 ([검증](10-verification.md#12번-문서낱말-비-검증-jev)).
  - 크롬·파이어폭스: Enter `keydown`이 조합 중(`event.isComposing === true`)으로 먼저 오고, 크롬은 조합이 끝난 뒤 Enter `keydown`이 한 번 더 올 수 있다.
  - 사파리: `compositionend`가 먼저 오고, Enter `keydown`은 `isComposing: false`, `keyCode: 229`로 온다.
- 그래서 이렇게 처리한다.
  1. 조합 중 Enter(`isComposing`)는 바로 제출하지 않고 "제출 대기"로 표시한 뒤, `compositionend` 다음에 입력칸 값으로 한 번 제출한다.
  2. 조합 중이 아닌 Enter는 입력칸 값으로 제출한다.
  3. 제출하면 입력칸을 비우고, **빈 입력칸의 Enter는 무시**한다. 이렇게 하면 Enter가 두 번 와도 한 번만 제출된다.
- 태블릿은 가상 키보드가 올라오면 게임 영역이 줄어든다. 바닥 선을 가상 키보드 위로 올리고, 낙하 거리가 줄면 떨어지는 시간(초)은 그대로 유지되게 속도를 다시 계산한다.

## 6. 화면

- 배경: 07의 캔디 테마에 옅은 빗줄기. 요즘 말 꾸러미는 **픽셀 테마**(07의 유행어 스킨).
- 낱말: 둥근 빗방울 모양 칩 안에 글자. 글자와 배경 대비 4.5:1 이상, 연령대 글자 크기 설정을 따른다.
- 없앨 때: 빗방울이 터지며 작은 물방울 효과와 효과음(설정에서 끌 수 있음). 운영체제의 "동작 줄이기"(`prefers-reduced-motion`)가 켜져 있으면 터지는 효과 없이 사라지게만 한다.
- 바닥: 새싹 3개. 낱말이 닿으면 하나씩 시든다.
- 화면 흐름: 메인 메뉴 → 미니게임 → 꾸러미 고르기 → 게임 → 공통 결과 화면 ([03](03-screens-and-flow.md))

## 7. 구현 메모

- 애니메이션은 `requestAnimationFrame`으로 돌리고, 위치는 **지난 프레임과의 시간 차이**로 계산한다 (화면 주사율이 달라도 같은 속도).
- `visibilitychange`로 탭이 가려지면 일시정지한다. 돌아오면 "계속하기" 버튼을 눌러야 다시 시작한다.
- 게임 규칙(낱말 고르기, 맞힘 판정, 속도 계산, 점수)은 화면과 떼어 `src/typing/` 또는 `src/games/wordRain/`의 순수 함수로 만들고 단위 테스트를 붙인다.
- 단위 테스트에 넣을 것
  - 점수: `갓생` 20점, 콤보 끊김
  - 같은 낱말 두 개 중 아래 것이 없어진다
  - 초등학생 프로필에서 `kidSafe: false` 유행어가 뽑히지 않는다
  - 유행어 모드가 꺼져 있으면 요즘 말 꾸러미가 없다
  - 30초마다 10% 빨라지고 2.5배에서 멈춘다
  - 조합 중 Enter는 조합이 끝난 값으로 한 번만 제출된다 (Enter 이벤트가 두 번 와도 한 번)
  - 빈 입력칸의 Enter는 무시된다
