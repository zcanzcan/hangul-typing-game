# 06. 유행어 운영

유행어는 계속 바뀌므로 **주기적인 업데이트가 필수**다. 두 가지 길로 들어온다.

## 1. 사용자가 직접 추가 (설정 화면)

- 설정 → 유행어 모드 → "유행어 추가"에서 낱말, 뜻, 예문(선택)을 입력한다.
- 저장 전에 **금칙어 필터**를 거친다. 걸리면 저장하지 않고 "학생에게 알맞지 않은 말이에요"라고 안내한다.
- 추가한 유행어는 그 기기에만 저장되고(`origin: "custom"`), 바로 카드게임 문제와 낱말 비의 "요즘 말" 꾸러미에 나온다.
- 선생님이 반 전체에 나눠 줄 수 있도록 **내보내기/가져오기(JSON 파일)** 를 P1로 둔다.

## 2. 기본 목록 업데이트 (운영자)

기본 유행어 목록은 이 저장소의 `public/data/slang.json`(개발 후 경로)에서 관리한다.

### 업데이트 주기

- **월 1회** 정기 업데이트 (매월 첫째 주)
- 크게 화제가 된 말은 수시 추가

### 업데이트 절차

1. **후보 모으기:** 뉴스, 방송, 국립국어원 "우리말샘" 신어, 연말 유행어 결산 기사 등에서 후보를 모은다. AI 도구로 후보 목록 초안을 만들어도 된다.
2. **검증:** 각 후보에 대해 뜻이 맞는지, 실제로 널리 쓰였는지 출처 2개 이상으로 확인한다.
3. **학생용 검수:** 욕설, 비하, 혐오, 특정 집단 조롱, 선정적 의미가 있으면 제외한다. 애매하면 `kidSafe: false`로 두고 성인에게만 보여준다.
4. **기록:** `addedAt`, `popularFrom`, `source`를 채운다.
5. **옛 유행어 정리:** 1년 넘게 안 쓰이는 말은 삭제하지 않고 `status: "archived"`로 바꿔 "옛 유행어" 모음에 남긴다.
6. **반영:** `version`을 오늘 날짜로 바꾸고 Pull Request로 올린다. 병합되면 배포 사이트에 자동 반영된다.

### 자동화 (선택)

- GitHub Actions 또는 Claude 루틴으로 매월 후보 목록 초안을 만들어 **검수 대기 PR**을 여는 방식이 가능하다.
- 자동으로 만든 후보도 반드시 사람이 검수한 뒤 병합한다.

## 금칙어 필터

- 기본 금칙어 목록을 `public/data/blocklist.json`에 둔다 (공개 저장소이므로 목록 자체는 최소한으로, 패턴 위주로 관리).
- 자모 분리·띄어쓰기·특수문자 끼워 넣기(예: `ㅅ.ㅂ`)도 잡도록 비교 전에 정규화한다.
- 필터는 완벽할 수 없으므로 기본 목록은 반드시 사람이 검수한다.

## 낱말 비(미니게임)에 쓰기

- 같은 `slang.json`을 쓴다. 게임용 목록을 따로 만들지 않으므로 월 1회 업데이트가 그대로 게임에 반영된다.
- `status: "active"`만 쓰고, 초등학생 프로필은 `kidSafe: true`만 쓴다.
- 떨어지는 칩에 들어가야 하므로 띄어쓰기가 있거나 연령대 글자 수를 넘는 말은 게임에서 빠진다 (카드게임에는 그대로 나온다). 자세한 규칙은 [12. 낱말 비](12-word-rain.md).

## 카드게임 오답 보기 만들기

- 뜻 4개 중 정답 1개 + 다른 유행어의 뜻 3개를 무작위로 뽑는다.
- 유행어가 4개 미만이면 표준어 낱말 뜻을 섞어서 채운다.
