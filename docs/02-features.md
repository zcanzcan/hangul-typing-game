# 02. 기능 명세

우선순위 표시: **P0** = 첫 버전(MVP) 필수, **P1** = 두 번째 버전, **P2** = 나중에

## 1. 타자 연습

| ID | 기능 | 우선순위 | 설명 |
|---|---|---|---|
| T-1 | 자리 연습 | P0 | 두벌식 자판의 기본 자리(ㅁㄴㅇㄹ / ㅓㅏㅣ)부터 윗줄, 아랫줄 순서로 한 글자씩 연습 |
| T-2 | 낱말 연습 | P0 | 표준어 낱말을 하나씩 입력. 입력이 끝나면 뜻 카드가 뒤집힘 |
| T-3 | 짧은 문장 연습 | P0 | 속담, 쉬운 문장 입력 |
| T-4 | 긴 문장 연습 | P1 | 성인용 긴 글 연습 |
| T-5 | 단계식 진행 | P0 | 자리 → 낱말 → 문장. 정확도 기준을 넘으면 다음 단계 열림 |
| T-6 | 받침·쌍자음 단계 | P1 | 받침 없는 글자 → 받침 → 쌍자음(ㄲㄸㅃㅆㅉ) 순서 |
| T-7 | 화면 키보드 | P0 | 두벌식 자판 표시. 다음에 누를 키를 빛내 줌. 태블릿에서는 직접 눌러 입력 가능 |
| T-8 | 떨어지는 낱말 막기 (미니게임) | P1 | 위에서 떨어지는 낱말을 바닥에 닿기 전에 입력해서 없애기 |

## 2. 뜻 익히기

| ID | 기능 | 우선순위 | 설명 |
|---|---|---|---|
| M-1 | 낱말과 뜻 함께 보기 | P0 | 낱말 입력 후 뜻, 예문을 카드로 보여줌 |
| M-2 | 그림 카드 | P1 | 초등학생용. 낱말에 그림(이모지 또는 일러스트) 표시 |
| M-3 | 틀린 낱말 다시 연습 | P0 | 틀린 낱말을 기기에 저장, "다시 연습"에서 모아서 복습 |
| M-4 | 오늘의 낱말 | P1 | 메인 화면에 하루 한 낱말과 뜻 |
| M-5 | 헷갈리는 맞춤법 | P1 | 되/돼, 안/않, 로서/로써 등. 성인 기본 |
| M-6 | 틀린 맞춤법 고치기 | P2 | 틀린 문장을 보고 바르게 고쳐 입력 |
| M-7 | 속담·사자성어 뜻 퀴즈 | P2 | 성인용 퀴즈 |

## 3. 유행어 모드

| ID | 기능 | 우선순위 | 설명 |
|---|---|---|---|
| S-1 | 유행어 모드 켜기/끄기 | P0 | 설정에서 켬. 기본은 꺼짐 |
| S-2 | 뜻 맞히기 카드게임 | P0 | 유행어 카드를 보고 뜻 4개 중 하나 고르기. 맞히면 유행어를 타자로 한 번 입력 |
| S-3 | 설정에서 유행어 직접 추가 | P0 | 낱말, 뜻, 예문 입력. 기기에 저장 |
| S-4 | 학생용 검수 | P0 | 욕설·비하·혐오 표현 금칙어 필터. 기본 목록은 검수된 것만 포함 |
| S-5 | 등록 날짜와 출처 | P1 | 유행어마다 언제, 어디서 유행했는지 표시 |
| S-6 | 옛 유행어 보관 | P1 | 유행이 지난 말은 "옛 유행어" 모음으로 이동 |
| S-7 | 유행어 목록 원격 업데이트 | P1 | 앱이 저장소의 최신 유행어 JSON을 불러옴 ([06. 유행어 운영](06-slang-operations.md)) |

## 4. 점수판

| ID | 기능 | 우선순위 | 설명 |
|---|---|---|---|
| R-1 | 결과 화면 | P0 | 타수, 정확도, 점수, 틀린 낱말 표시 |
| R-2 | 내 기록 | P0 | 모드별 최고 기록과 최근 기록. 기기에 저장 |
| R-3 | 최고 기록 갱신 축하 | P0 | 최고 기록을 넘으면 축하 효과와 스티커 |
| R-4 | 가족 점수판 | P1 | 한 기기에서 여러 닉네임으로 기록 비교 (손주와 할아버지 대결) |
| R-5 | 반 점수판 (선생님용) | P2 | 선생님이 반 코드를 만들고 학생들이 참여. 서버 필요 |

## 5. 설정과 접근성

| ID | 기능 | 우선순위 | 설명 |
|---|---|---|---|
| A-1 | 연령대 선택 | P0 | 처음 접속 시 고름. 글씨, 속도, 난이도 프리셋 적용 |
| A-2 | 닉네임으로 시작 | P0 | 로그인 없음. 개인정보 수집하지 않음 |
| A-3 | 글자 크기 3단계 | P0 | 보통 / 크게 / 아주 크게 |
| A-4 | 속도 조절 | P1 | 시간 제한 켜기/끄기, 미니게임 속도 |
| A-5 | 소리 읽어주기 | P1 | 브라우저 음성 합성(Web Speech API)으로 낱말과 뜻 읽기. 한국어 목소리는 기기마다 있을 수도 없을 수도 있으므로, 없으면 버튼을 숨긴다 |
| A-6 | 효과음 켜기/끄기 | P0 | |
| A-7 | PWA 설치, 오프라인 사용 | P1 | 홈 화면에 추가, 인터넷 없이 연습 |
| A-8 | 하루 10분 목표 도장 | P2 | 연습 시간 누적, 달력 도장 |

## 첫 버전(MVP) 요약

P0만 모으면 다음과 같다.

- 시작(연령대, 닉네임) → 메인 메뉴
- 자리 연습, 낱말 연습(뜻 카드), 짧은 문장 연습, 화면 키보드
- 유행어 카드게임, 유행어 직접 추가, 금칙어 필터
- 결과 화면, 내 기록, 최고 기록 축하, 틀린 낱말 다시 연습
- 글자 크기 3단계, 효과음 설정
- 모든 기록은 기기 안(localStorage/IndexedDB)에 저장, 서버 없음
