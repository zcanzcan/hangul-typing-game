2026-10-09 공식 공개 검색 결과와 항목 원문을 확인해 51개 표제어의 의미를 선별했습니다.
API 발급, 실시간 사전 요청, 전체 사전 내려받기나 이메일 전송을 사용하지 않았습니다.
뜻풀이 문장은 원문 그대로 유지합니다. 웹 표시의 공백을 정리하고 의미를 하나씩 선택했으며,
게임용 ID·난도·대상·태그·이모지를 결합했습니다. 게임 분류는 국어원의 교육 등급이 아닙니다.
words.json의 source와 provenance에 표제어 ID·의미 번호·원문 URL·확인일·가공 내용을 기록했습니다.
다른 게임의 단어 풀에도 이 선별 목록을 사용합니다. 섞은 꾸러미는 별도 유행어 자료도 사용합니다.

사전 예문, 이미지, 발음 음원, 출전 있는 인용문과 기타 멀티미디어는 포함하지 않았습니다.
과거 51개 뜻풀이와 예문의 실제 출처는 불명확했습니다. 과거 자료가 공식 사전이거나
사용자가 직접 작성했다는 보증은 하지 않습니다. 뜻풀이는 교체하고 예문은 제거했습니다.

재배포 시 저작자·원 자료·라이선스와 가공 표시를 보존하세요.
변경한 사전 자료는 동일조건변경허락을 따르며 이용자의 권리를 제한하는 조건을 추가하지 마세요.
원 자료는 있는 그대로 제공되며 보증 없이 이용됩니다. 세부 조건은 위 이용허락규약을 따릅니다.
이 앱은 국립국어원의 공식 서비스·추천·인증을 받은 제품이 아닙니다.

기존 프로젝트 학습 자료이며 이번 51개 공식 사전 뜻풀이 검증에 포함되지 않습니다.
해당 자료의 작성 경위·교육적 적합성은 추가 검토가 필요합니다.
